One funny word for your Wi-Fi network — the most honest name a router could wear — written by a tiny stdlib-only Python program for make.fun's "One Word for Your Wi-Fi" bounty.

## Run it

```sh
python3 main.py
```

It writes the word to `/output/entry.txt`.
